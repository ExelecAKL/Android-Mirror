# Android Mirror 1.1.4

This app update fixes another minimize issue found during physical phone testing.

- **Stay in the background:** typing or clicking elsewhere no longer reopens a mirror because Windows retained its old foreground state.
- **Reliable taskbar restoration:** handle taskbar clicks that arrive as another minimize, waiting for the transition before restoring the mirror.
- **Keep the right dimensions:** preserve the last drawable portrait/landscape size and ignore temporary minimized title-bar bounds. Includes the rotation and maximized-window improvements from 1.1.3.

This is an **App update**. Your settings and current mirroring engine are preserved. Existing 1.1.1–1.1.3 installations receive **Install update / Remind me later** on their next enabled automatic check. Use Settings to check sooner. Portable copies open the download page.

## Validation

Physical phone testing verified continuing Windows capture and landscape/portrait resizing while the mirror remained in the background. The isolated SDL/Windows Graphics Capture checks cover repeated rotations, taskbar toggling, unrelated later input, restore dimensions, maximized rotation, unmaximize, setting changes, and cleanup. The 58 regular app tests and eight installer checks pass.

Physical restore/maximize round trips, a new end-to-end OBS/Discord session, and mixed-DPI monitor checks remain unverified. Use OBS Window Capture's modern WGC/Automatic method. A deliberately fixed or maximized window and a different OBS canvas aspect ratio can still produce normal letterboxing. See [validation details](https://github.com/ExelecAKL/Android-Mirror/blob/main/docs/VALIDATION.md).
