# Android Mirror 1.1.2

A small app update that corrects Windows notification branding across the app.

- Repair the Start menu shortcut identity used by Windows to show **Android Mirror** and the app logo in notification headers, replacing the internal `Exelec.AndroidMirror.Desktop` label.
- Restore Windows' **blue information symbol** in the notification body.
- Apply the shared fix to all four notification types: **running in the tray**, **device connected**, **app update**, and **engine based update**.
- Repair older shortcut metadata automatically and include the matching identity and logo in newly installed shortcuts.
- Preserve saved settings and the current mirroring engine when updating.

## Updating

Existing **1.1.1** installations receive **Install update / Remind me later** on their next automatic app-release check, when enabled. Checks run daily; **Settings → Check for updates** can check sooner. Installed copies download the verified installer, request normal Windows administrator approval, and restart after updating. Portable copies open the release download page.

Version **1.1.0** needs one manual installation of the latest release because it predates app-update checks. Older notification history may keep its previous appearance; this fix applies to newly delivered notifications.

## Downloads

- **Android-Mirror-1.1.2-Setup.exe** — installer and upgrade for Program Files installations.
- **Android-Mirror-1.1.2-Windows-x64.zip** — portable app.
- **Android-Mirror-1.1.2-Runtime-Sources.zip** — matching bundled runtime sources and licence metadata.
- **SHA256SUMS.txt** — SHA-256 checksums.

Windows 10/11 x64 and .NET Framework 4.8 are required. The executables are unsigned.

## Validation

58 app/connection/update checks and eight installer checks. Native shell checks exercise all four notification routes and their messages, information symbol, and exact embedded logo. Installer checks read back real Windows shortcut identity, target, and icon metadata and cover repair and cleanup ownership. A live Windows app-resolver check reports Android Mirror for the registered identity. See [validation details](https://github.com/ExelecAKL/Android-Mirror/blob/main/docs/VALIDATION.md) for visual and hardware limitations.
