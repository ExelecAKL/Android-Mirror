# Android Mirror 1.1.1

Keep your mirror live in the background, and receive Android Mirror updates directly in the app.

- **Keep sharing when minimized** is enabled by default. The mirror stays drawable outside the desktop so modern Windows window capture can continue receiving frames. Its taskbar icon or Alt+Tab brings it back.
- **Android Mirror updates**, separate from engine updates: daily release checks, release notes, and a Windows-style **Install update / Remind me later** popup. Installed copies download a verified installer and restart after updating. Portable copies open the release download page.
- Both popup types explain **What’s changed** and clearly label **App update** or **Engine based update**. Engine updates require approval before installing and wait for active mirrors to stop.
- App upgrades preserve your settings and current engine, including newer/custom engine files. Interrupted app-file replacement attempts rollback. The app restarts without inheriting installer administrator privileges.
- Connection logs use Android Mirror branding and [our repository](https://github.com/ExelecAKL/Android-Mirror), retaining useful connection/error information.
- Native Windows notifications use the Android Mirror logo and a dedicated application identity.
- Plugging in one newly discovered, authorized device opens its mirror immediately when automatic connection is enabled, including alongside an existing mirror. Explicit Stop and deselection choices remain respected.

## Updating from 1.1.0

Install **Android-Mirror-1.1.1-Setup.exe** once. Version 1.1.0 has no app-update checker and cannot display a new update prompt remotely. After this update, future app releases can offer **Install update** or **Remind me later** automatically. Your saved preferences and installed engine are kept.

## Downloads

- **Android-Mirror-1.1.1-Setup.exe** — Program Files installer, also updates an existing installation.
- **Android-Mirror-1.1.1-Windows-x64.zip** — portable copy; extract and open Android Mirror.exe.
- **Android-Mirror-1.1.1-Runtime-Sources.zip** — matching bundled runtime sources and licence/build metadata.
- **SHA256SUMS.txt** — SHA-256 checksums for the downloads.

Windows 10/11 x64 and .NET Framework 4.8 are required. The executables are unsigned. This is a GitHub release, not a Microsoft Store listing.

## Validation

58 automated app/connection/update checks and seven installer checks pass. Live tests using the bundled SDL renderer and real Windows Graphics Capture confirm changing frames while the window is in the background, normal/maximized restoration, repeated minimize, setting changes, and cleanup.

For OBS Window Capture, use Automatic or the modern Windows 10 (1903 and up) / WGC method. Legacy BitBlt and whole-display capture are not supported by background parking. A real OBS recording and Discord call still need end-to-end verification. Physical QR pairing, device audio/input, and cable/Wi-Fi handover also remain hardware validation tasks. Windows controls notification delivery and may retain older notification history.
