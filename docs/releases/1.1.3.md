# Android Mirror 1.1.3

This app update improves minimizing and rotating a mirror while screen sharing.

- **Correct portrait/landscape sizing:** restoring a mirror retains its latest rotated dimensions, instead of forcing it back into the old shape with large gray borders.
- **Stay minimized:** delayed foreground changes without new PC input no longer reopen the background mirror. Repeated minimize requests are handled too.
- **Better maximized behavior:** rotation continues in the background; restoring returns to maximized, and unmaximizing keeps the new rotated size.
- **Continue capturing:** the same mirror window remains drawable, with movement that preserves its size and avoids repeatedly rebuilding the frame.

This is an **App update**. Your settings and current mirroring engine are preserved. Existing 1.1.1/1.1.2 installations receive **Install update / Remind me later** on their next enabled automatic check. Use Settings to check sooner. Portable copies open the download page.

## Validation

The new SDL/Windows Graphics Capture test reproduces the stale orientation-size failure in the released 1.1.2 code. The fix passes repeated portrait/landscape changes, continuing captured frames, repeat minimize, activation without fresh input, maximized rotation, unmaximize, setting changes, and cleanup. The regular 58 app tests and eight installer checks also pass.

Use OBS Window Capture's modern WGC/Automatic method. Deliberately fixed or maximized windows and a different OBS canvas aspect ratio can still produce normal letterboxing. A new end-to-end OBS/Discord session and mixed-DPI monitor checks remain to be verified; see [validation details](https://github.com/ExelecAKL/Android-Mirror/blob/main/docs/VALIDATION.md).
